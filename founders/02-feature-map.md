# Feature map

Use the existing [consolidated product roadmap](../docs/CONSOLIDATED_PRODUCT_ROADMAP.md) as the authoritative feature inventory and completion classification.

Coach and Parent journeys already exist. Private workspace candidates are engineering progress, not proof that corresponding live features are complete.

Every new feature specification, scenario inventory, and release summary should reuse its roadmap feature ID. For work outside the inventory, define a stable ID and record its authoritative specification before implementation.
