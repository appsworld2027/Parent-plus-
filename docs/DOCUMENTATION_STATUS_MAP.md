# Documentation status map

**Status:** Active

- **Active:** current rules, requirements, plans, or status.
- **Reference:** supporting detail that does not override Active documents.
- **Historical:** dated evidence from an earlier state.
- **Archive:** retained for traceability and not used for current work.

AI agents should use Active documents first and record the sources used in the
task plan or closeout. Founders can sample one document from each category to
check that ownership, dates, and limits are clear.
