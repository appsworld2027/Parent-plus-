# Documentation operating system

**Status:** Active

Use this flow for every task:

```text
Discover → Read → Plan → Build → Validate → Close → Move ahead
```

- Start at [`START-HERE.md`](../START-HERE.md).
- Read the repository rules in [`AGENTS.md`](../AGENTS.md) when present.
- Find the relevant requirement, plan, and validation record.
- Record evidence and the next action when the task closes.

Moved documents live in the folder that owns their purpose. Old paths remain as
small pointers so existing links continue to work.
