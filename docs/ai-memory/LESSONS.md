# Lessons

- 2026-11-22 · Coach "Needs you": green tests + AI review still missed a false "All caught up" while loading and on error. Contracts must include loading / empty / error / offline / large-data ACs. (Evidence: QA audit, Parent_Plus_QA_Coverage_Results.xlsx D-01.)
- 2026-11-23 · Overdue fees (#42): the first agent-written spec failed for the wrong reason in 11 of 18 tests while its PR claimed success. Agent self-reports are not evidence; the acceptance gate and a second reviewer on another model are required. (Evidence: AI Org issue #62, PR #61.)
- 2026-11-24 · Model trial 3: Kimi K3.1 Pro at medium reasoning and Nemotron 3 Ultra both wrote a gate-passing 18-test spec in ~42 min; Kimi/GLM at low reasoning ran out of time. (Evidence: AI Org issue #66.)
- Agents must commit to feature branches only; `main` accepts pull requests only. (Evidence: #42, a revision committed to `main` before branch protection.)
- 2026-11-24 · Acceptance-test execution is not gate evidence: grading the pre-metadata spec against an 18-test JSON report reproduced `Acceptance-test gate: FAIL — 0/18` because `NEW-HOOKS` / `GUARD` / `RED-BECAUSE` declarations were absent; the corrected head gated `PASS — 18/18`. Re-run the gate after spec or metadata changes. (Evidence: [commit fd832e9](https://github.com/appsworld2027/Parent-plus-/commit/fd832e9f2005d8f1a7f740e56ccd91cc5f1bb7f4), [PR #45 gate](https://github.com/appsworld2027/Parent-plus-/pull/45#issuecomment-7132407900).)
- 2026-11-24 · Exercise plural and aggregate requirements with multiple values and assert every value plus the aggregate. AC-03 originally let a first-month-only implementation pass; the correction seeds two months for one student and asserts both months and their summed amount. (Evidence: [challenger finding](https://github.com/appsworld2027/Parent-plus-/pull/45#issuecomment-7130401002), [commit 9c2cdf5](https://github.com/appsworld2027/Parent-plus-/commit/9c2cdf5d073cf7e5ca3a5639557114079cf11ee5).)
