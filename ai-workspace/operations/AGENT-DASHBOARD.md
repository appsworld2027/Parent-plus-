# Parent Plus Agent Dashboard

The live dashboard is generated by [AppsWorld AI Organization dashboard](../../.github/workflows/ai-org-dashboard.yml). It runs every 30 minutes and on demand.

The dashboard combines recent AI Organization workflow runs and open Parent Plus work items. It shows workflow status, GitHub run links, and Feature/Test/Session/Response identifiers when supplied.

## Cross-repository visibility

Parent Plus's default `GITHUB_TOKEN` is scoped to Parent Plus and cannot read the private AI Organization repository. Without an optional repository secret named `AI_ORG_TOKEN`, the dashboard shows a clear `unavailable` row instead of a misleading GitHub 404. The token should be read-only and limited to Actions/metadata access for `appsworld2027/parent-plus-ai-org`.

## Where to view it

1. Open Parent Plus → **Actions**.
2. Select **AppsWorld AI Organization dashboard**.
3. Open the latest run.
4. Read the run summary or download `parent-plus-agent-dashboard`.

Missing identifiers are shown as `not supplied`; they are never invented.
